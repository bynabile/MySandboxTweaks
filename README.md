# 🚀 Windows Sandbox Automated Environment Setup

مجموعة سكربتات وإعدادات مخصصة لأتمتة بيئة **Windows Sandbox** بالكامل. تتيح لك هذه الأداة تشغيل نظام وهمي معزول وسريع ومُخصص مسبقاً مع تعطيل التأثيرات والمرئيات الزائدة، تطبيق الوضع الداكن، نقل عناصر سطح المكتب، وتشغيل البرامج تلقائياً دون ظهورها كأيقونات على سطح المكتب.

---

## 📂 هيكلية المشروع (Project Structure)

قم بوضع مستودع المشروع في المسار التالي على جهازك الرئيسي:

```text
C:\SandboxFiles\
├── Sandbox.wsb          # ملف تكوين وتشغيل البيئة المعزولة
├── tweaks.reg           # تعديلات الريجستري (إلغاء الأخبار، البحث، الألوان، الأنيميشن)
├── setup.bat            # السكربت التنفيذي الآلي عند الإقلاع
├── bg.jpg               # صورة خلفية سطح المكتب (قم بإضافة الصورة الخاصة بك)
├── README.md            # توثيق المشروع ودليل الاستخدام
└── DesktopItems\        # المجلد المخصص للعناصر المراد نقلها لسطح المكتب
    └── AutoRun\         # مجلد البرامج التي تعمل تلقائياً دون الظهور على سطح المكتب

```

---

## ⚙️ مميزات المشروع وظائف الملفات

* **`Sandbox.wsb`**: ملف التكوين الرئيسي الذي يربط مجلد المشروع بالنظام الوهمي، ويعطي أمراً بتشغيل الإعدادات تلقائياً عند الإقلاع.
* **`tweaks.reg`**: يتضمن التعديلات البرمجية الخاصة بالريجستري:
* إيقاف الأخبار والاهتمامات (News & Interests).
* إخفاء مربع البحث من شريط المهام.
* إلغاء التأثيرات المرئية والأنيميشن مع تنعيم الخطوط فقط.
* تفعيل الوضع الداكن (Dark Mode) وتصغير أيقونات سطح المكتب.


* **`setup.bat`**: السكربت التنفيذي الذي يُطبق تعديلات الريجستري، يُفعل إعدادات الواجهة بالذاكرة مباشرة، يغير الخلفية، ينقل عناصر سطح المكتب، ويشغل البرامج التلقائية.

---

## 🚀 طريقة الاستخدام (Quick Start)

1. **التحضير:**
تأكد من وجود مجلد المشروع كاملاً في المسار الرئيسي: `C:\SandboxFiles`.
2. **تخصيص المجلدات والصور:**
* ضع صورة الخلفية الخاصة بك باسم `bg.jpg` داخل المجلد الرئيسي.
* ضع البرامج أو الاختصارات المراد ظهورها على سطح المكتب داخل `DesktopItems`.
* **التشغيل المباشر:** ضع البرامج أو الملفات المراد فتحها تلقائياً فور الإقلاع دون أن تظهر كأيقونات على سطح المكتب داخل مجلد `DesktopItems\AutoRun`.


3. **التشغيل:**
اضغط مرتين على ملف `Sandbox.wsb` لبدء البيئة المعزولة والجاهزة بالكامل.
